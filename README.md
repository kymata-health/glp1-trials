# GLP-1 Trials Dataset

A sourced, machine-readable table of the pivotal clinical trials for GLP-1 medicines: semaglutide (Ozempic, Wegovy, Rybelsus, Wegovy pill), tirzepatide (Mounjaro, Zepbound) and orforglipron (Foundayo).

Maintained by the editorial team at **[Kymata Health](https://kymatahealth.com)**, an independent, evidence-graded health research site.

## What's in it

One row per trial, each with:

- trial name, registry ID (NCT) and the primary publication (journal, year, PMID, DOI)
- medicine, molecule and population (obesity, type 2 diabetes, cardiovascular disease)
- length in weeks and number of participants
- average body-weight change in the drug group and in the comparison group (placebo or the comparator drug), exactly as reported
- notes on the estimand where it differs from a plain start-to-end change (for example, trials with a lead-in period)

Every figure is checked against its primary publication. If a number here disagrees with the paper, the paper wins. Please open an issue.
